An example client website

This page stands in for a customer's own site. Serve it over HTTP and add its origin to the chatbot's allowlist:

python -m http.server 5500 --directory examples

Then create a chatbot whose allowed_origins contains http://localhost:5500, put its public key in the script tag at the bottom of this file, and reload.

The pink boxes and rotated button below are this page's own CSS, applied to prove the widget is not affected by them.
